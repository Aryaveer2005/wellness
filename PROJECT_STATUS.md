## 3. Known issues / needs owner

- 🔒 Vercel: after adding/changing env vars, **Redeploy** (they only apply to new deployments). Check https://wellness-two-liard.vercel.app/api/health — every value except `anthropicFallback` should be `true`.

- ⚠️ The final QA agent was stopped part-way by a usage limit (2026-10-21). Type check, lint and all page loads pass, but these items from the docs review may still be open — re-run the QA pass to confirm: (1) Reframer crisis path should show the red crisis card + tap-to-call (today the crisis text appears in the hint box); (2) small expression card during the session should show a visible "AI-generated photo" label; (3) settings download filename still `show-up-data-…`; (4) "Delete my data" leaves sound/voice-guide preferences; (5) voice-mode overlay not visually re-checked after the redesign.

- ⚠️ Don't run `npm run build` while `npm run dev` is running (they share `.next`). If dev fails with `EINVAL: invalid argument, readlink ... .next` (OneDrive quirk), stop it, delete the `.next` folder, and start again.

- ⚠️ NVIDIA's hosted NemoGuard topic-control endpoint returns HTTP 500 (their GPU error) — guard is skipped automatically and retried every 5 min; nothing to do on our side.
- 🔒 Rotate the NVIDIA keys (build.nvidia.com) and the Google Places key (Google Cloud) when convenient — they were pasted into an AI chat. In Google Cloud, also restrict the Places key to "Places API (New)" and set a budget alert.
- ℹ️ Voice mode is English (en-US). For Hindi/Hinglish, switch `NVIDIA_ASR_FUNCTION_ID` to the multilingual Parakeet model — not tested yet.
- ℹ️ AI quotas are in-memory per IP (reset on restart, not shared across servers) — fine for v1, use a shared store (e.g. Upstash/Redis) before scaling.
- ℹ️ Videos add ~20 MB (phones) / ~26 MB (desktop) total to the site, loaded only when on screen. Upload years in `public/videos/CREDITS.md` are estimates.

- 🔒 Helpline numbers, psychologist directory entries, privacy and terms text must be verified/supplied by the owner.
- 🔒 Still missing keys: Supabase (accounts). NVIDIA + Google Places keys are in place; Anthropic is optional.
- ⚠️ (Mirror server removed by CEO — adding any extra OSM host needs owner approval.) "Top 5 psychiatrists near me" without a Google key depends on free public OpenStreetMap (Overpass) servers. In testing (2026-10-20) they were overloaded (502/504/timeouts) and the search showed the friendly "couldn't reach the map service" message after ~20s. One earlier direct test did return Pune results. For reliable results add `GOOGLE_PLACES_API_KEY`. OSM data also includes some loosely tagged places (e.g. a career-counselling centre tagged "psychotherapist").
- ⚠️ Checked in a real browser (Edge, 360 / 768 / 1440, light + dark) on 2026-10-20. Still not checked: the AI chat with a real API key, and real iOS/Android devices (safe-area insets, touch scrolling).
- ℹ️ Running `npm run build` while `npm run dev` is running overwrites the dev server's `.next` folder and the dev site shows "Internal Server Error" until the dev server restarts (saving `next.config.ts` makes it restart itself). Stop the dev server before building.
- ℹ️ `components.json` still says `"iconLibrary": "lucide"` — if someone runs the shadcn CLI to add a component, swap its icon imports to `@/components/icons`.
